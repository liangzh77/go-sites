# 水墨视频

目标是让一张张静止的画把故事讲清楚。默认纸本水彩、普通话单人讲述；用户当次指定的画风、画幅、声音和交付范围优先。**新故事从头做；已有项目从最近一次确认的版本续做。** 不要把上次的故事、角色、五镜数量或视频时长变成模板。

## 新片流程

1. **故事与分镜。** 只讲用户指定的范围；若还在选题，先确定故事。改编要核对出处，标明传说、史实与改写。写能自然说出口的旁白，补足画面看不出的因果，不逐项描述动作。每镜写下「对应旁白｜定格瞬间｜视线起止｜推、拉、移或停的理由」，预留字幕与裁切空间。
2. **出图，停下来给用户看。** 先打开本技能的 `assets/风格板.jpg`，仅参考线条、纸纹和水彩笔触。重新设计人物、道具和场景，用 OpenAI 内置 `image_gen` 先画最能确定角色和环境的一镜，再用这张原画约束其余镜头。出单幅无字、无边框横画（用户指定竖屏则改构图），不把拼贴预览切成原画。按下方清单逐张和连起来审，再交付按序编号的整组预览及原图。**未确认图片，不生成旁白。**
3. **纯旁白，停下来给用户听。** 按已确认的画面复核稿件。默认 Microsoft Edge TTS 的普通话男声云希 `zh-CN-YunxiNeural`，原速、原音高。整段合成，必要时按自然段；同时保存字词边界、合成用文本和正式字幕文本。检查人名、重音、停顿、首尾有无缺字；校音用的同音字不进入字幕。先交付无配乐、无环境声的录音，**未确认声音，不剪成片。** “可以”只通过刚展示的阶段。
4. **按声音剪辑。** 按实际录音和边界定切镜与分句字幕，不用平均镜长。重要揭示不要早于旁白。只移动取景框，不动人物或背景；需要等观众观察就定镜。默认横屏 1080p、H.264/AAC MP4。检查整片可解码，抽看各镜进出点、高潮切点、字幕可读性与末尾留白，核对音画总长，再给成片链接。

## 审画：先讲得通，再谈好不好看

- **人物**：从头、肩、腰胯、膝盖到脚看整个人的比例和重心；再沿肩、肘、腕检查手掌朝向与接触面。坐姿不要把躯干压短。反复局修仍别扭，回到角色定稿重画整镜，而非在错的骨架上修手、缩头。
- **道具**：问“这个人在此情此景会怎么拿、放、用它？”不要为了辨认道具强行向镜头展示。前一镜提着的包，后一镜搁在哪里、何时打开，应当说得通。
- **空间与事件**：手势从谁指向哪里，是否真的需要特写？颜色是材质还是一束光？发生倒塌等变化时，要能看出原物、运动方向与结果，而不只是一个好看的缺口。
- **连续性**：从缩略图看视觉重点，再看原图的解剖细节和运镜首尾裁切。对照相邻镜的角色、服饰、物件、尺度、视线与旁白；不因为一张画单独漂亮就通过。

## 续做与局部返工

- 每个故事放在独立项目目录。保留编号原画、分镜稿、录音与词时间、字幕、逐镜片段和版本化成片。在项目内记录「镜号 → 当前原画 → 旁白区间/帧范围 → 确认状态」，不要把作品或日志写到技能目录。
- 用户只要改图，就给新版原图；说“视频也改了”或在已约定的成片修订中，直接替换指定镜头，给**新原图和新版成片**，注明从几秒看。保留旧版。未受影响的镜头、原音轨、字幕与切点不重做；导出后从**新视频**抽一帧验证确已替换。
- 只改运镜不用重画；换配音须重新对齐切镜和字幕。若画面改动与原旁白冲突，指出具体句子并提供修订试听，不静默改掉已确认录音。
- 出图、语音或编码工具不可用时说明卡在哪一步；可以交付已完成的素材，但不要把提示词或分镜稿当成已经出图。更换为新的付费服务先征得同意。
