# 波普贴纸工作室

一套静态插画、一份动作时间轴、两个平等的出口。用户说“互动网页”就输出 HTML，说“视频”就输出 MP4，说“两者都要”或没有限定时就同时交付。网页是可滚动、可倒退的实时舞台，不是嵌入视频；视频是本地逐帧渲染，不是网页录屏。图像模型只画静态素材；不调用 LibTV、MAGI-2 或其他视频生成服务。默认不部署、不发布。

## 1 · 定风格和动作
先看本技能的 `references/style-board.jpg`：参考**画法**，不要把牛排、锅或旧故事当成其他选题的内容。风格是**复古丝网印刷波普插画 + 刀版贴纸**：奶油纸、炭黑墨线、局部粗细不均的半调网点、轻微套色偏移，主色用酒红与芥末黄；主体有体积，不是扁平几何图标。贴纸保留窄奶油白边，不加外投影。

按用户指定的时长、画幅、主题；缺省 10 秒、16:9、24fps。先拆成可见动作而不只列场景。为每个动作写下起止时间、谁移动、接触谁、前后状态、何时停住。动作太多则删减次要步骤，不把中间动作挤成一闪而过。

## 2 · 只生成图片
**素材由 Agent 生成，不是用户的前置任务。** 收到主题后直接列图层清单，并用当前 Agent 已配置的图像生成工具绘制本次需要的原创静态插画；在 Codex 优先按内置 `imagegen` 技能使用 `image_gen`。无需先问用户要图片、参考链接或素材授权。技能内附的风格板只参考画法，示例素材不用于新项目。只有用户主动指定了要保留的自有素材，或在修订本次作品时，才复用相应图层；其余仍自行生成。每件独立运动的物体单独一张透明图；同一物体有空/满、生/熟、开/合时，从第一张编辑出同视角变体，保持画布尺寸与锚点一致。背景与字幕分开，文字由代码排版。可组合成精灵表以节省生图次数，但只在所有对象都能完整切开时使用。

提示词骨架：「[主体、状态、视角、朝向]，法国小酒馆印刷海报式套色插画，奶油纸材质、炭黑线、酒红和芥末黄，半调网点，形体清晰。单个完整剪影，均匀留白，透明背景，地面和外投影留空。」根据主题改意象，不必每次都是法国场景。把实际生成文件复制到**本次工程**，检查 alpha、白边和手柄等细节。只有缺白边时才用 `scripts/outline.py`，成组变体保持同尺寸和留白。

**没有生图工具或调用失败，不改变素材来源。** 先检查当前会话实际可用的生图工具；如果确实不可用，停在生图步骤，说明缺少的能力或实际报错，建议启用生图工具或切换到支持生图的会话后继续。不要搜索、下载或推荐网上现成图片，不要询问“是否授权使用网上素材”，也不要改为要求用户上传图片。不得自行转用付费 API、视频模型、占位图或旧示例图，不得声称已经生成图片。

## 3 · 写代码，让动作成立
将素材、时间轴和渲染命令保存在项目里；不要在技能目录内制作新项目。简单动作复制 `examples/scene.json` 的结构，用 `scripts/export_web.py` 导出完全内嵌素材的单文件 HTML、用 `scripts/render.py` 导出 MP4。网页自带单舞台、滚动取景、进度拖动和章节跳转，支持手机；按主题填写标题、章节与文字说明。复杂遮挡、液体、关节等可在项目内扩展代码；先看 `references/motion.md`。无需另做参考视频、模拟鼠标滚动或实时录屏。

运行（SKILL 指本技能目录；scene 中图片路径相对 scene.json）：
```bash
# 仅选需要的出口；两个都要时依次执行
uv run --with pillow python3 "$SKILL/scripts/export_web.py" ./scene.json ./index.html
uv run --with pillow python3 "$SKILL/scripts/render.py" ./scene.json ./film.mp4
```
网页无需服务器或 FFmpeg，双击即可查看；视频导出需要本机 FFmpeg。如已有 Pillow，可直接用 python3。渲染器默认静音，音效或配乐按需求另加，不捏造“带音乐”。示例仅用于测试安装，不是新的生成结果。

## 4 · 验收和交付
用 ffprobe 查时长、画幅、帧率；抽起/中/末和关键接触点前后帧，看动作再交付，不以“能播放”代替正确。示例：
```bash
ffmpeg -v error -i film.mp4 -vf 'fps=2,scale=240:-1,tile=5x4' -frames:v 1 contact.jpg
```
网页在桌面和手机尺寸验证滚动、倒退、拖动与章节跳转；视频验证上述帧检。双输出时比对相同时间点的构图、顺序与动作。只运行本次输出需要的检查，交付 HTML 和/或可播放 MP4 的绝对路径，简述哪些图是生成的、哪些动作用代码实现。保存素材和可重新渲染的工程。用户修改某处时优先只改相应图层、锚点或时间段，复用其余已确认素材。
