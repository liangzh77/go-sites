# 数学判卷页 · 实时上传判卷区（增量设计稿）

## 1. 信息架构

页面自上而下：**顶部入口条 → 实时判卷区 → 预置示例 Case 1 → 预置示例 Case 2**（两个静态图片+表格一字不动）。

- **顶部入口条**（`position: sticky` 不需要，置于页首即可）：一句说明「两个预置示例 + 实时上传判卷」+ 主按钮「⬇ 去实时判卷」，锚点 `#live-grading` 平滑滚动，`:target` 时实时区描边 2px `#b84e10` 闪烁一次提示位置。
- 实时区与示例区之间加分隔条：细线 + 小标签「以下为预置示例，不消耗额度」，避免混淆。

## 2. 实时判卷区布局（`<section id="live-grading">`）

暖白底 `#fcfbf8` 上铺白色卡片，14px 圆角、1px 边框 `#e8e2d8`，复用 essay.css 的卡片与按钮类。

1. **标题区**：「实时 AI 判卷」+ 徽标 `实时生成 · deepseek-v4.1-flash`，与预置示例的「预置结果」徽标颜色区分（橙色实心 vs 灰色描边）。
2. **上传卡片**：虚线拖放区（拖拽悬停时边框变橙、底色 `#fdf3ec`），内含图标 + 「点击选择 / 拖入 / Ctrl+V 粘贴图片」，下方小字「JPEG/PNG/WebP ≤5MB，浏览器自动压缩至最长边 2400px JPEG 并去除元数据」。
3. **预览条**：缩略图（点击进现有图片灯箱）、文件名、压缩后大小、「删除/换图」按钮。
4. **提示区**（icon+两行灰字）：「一次一页，多页请分次提交；上传前请遮盖姓名/学校/学号。本站不保存图片与结果，模型服务按其政策处理。」
5. **同意勾选**：checkbox + 「我已遮盖个人信息并同意发送图片给 AI 模型处理」，未勾选时主按钮 disabled 并带 `title` 说明。
6. **主按钮**：「开始 AI 判卷」（橙色实心，复用作文页主按钮样式），右侧固定提示词摘要「提示词：作为初一数学老师判卷 · 仅图片无需文字」。

## 3. 状态机与交互

`空态 → 压缩中 → 待提交（预览+未勾选/可提交）→ 请求中 → 成功 / 各失败态`

- **压缩中**：按钮区显示 spinner +「正在压缩图片…」，提交锁立即生效。
- **请求中**：按钮变「判卷中…（最长约2分钟）」+ spinner，禁用删除/换图/重复点击；前端 118s AbortController 超时，后端 110s。
- **成功**：结果区顶部橙色徽标「本次实时生成 · deepseek-v4.1-flash · 刚刚」；渲染**逐题表格**（题号｜学生作答｜判定｜批注），判定值用彩色 pill：正确绿、错误红、部分正确橙、未作答灰、待确认黄底「⚠ 待确认」；表格下方「总体说明」段落 + 常驻提醒条「AI 可能误判，模糊处已标待确认，请老师复核」；右上角「复制结果（Markdown）」复用现有复制组件与 toast。
- **失败态**（统一错误条，红色左边框，保留图片与勾选状态，按钮恢复为「重试」）：
  - 读图失败/格式超限：「无法读取图片，请更换 JPEG/PNG/WebP ≤5MB」；
  - 额度耗尽：「今日 50 次额度已用完，明天再来」；
  - 限流/忙：「服务繁忙，请稍后重试」；
  - 网络错误/超时：「网络异常/判卷超时，图片已保留，可直接重试」。
- **删除/换图**：清空旧结果与错误条，回到待提交态。**不自动发起判卷**：进入页面仅 `GET /status` 一次拉取剩余额度并显示「今日剩余 N 次」；预置示例的一切操作零请求。

## 4. 移动端（≥320px）

- 单列布局，拖放区高度压至 140px；预览缩略图 72px，文件名 `text-overflow: ellipsis`。
- 结果表格包 `.table-scroll { overflow-x:auto; -webkit-overflow-scrolling:touch }`，局部横向滚动、页面零溢出；表格 `min-width: 560px`，判定列 sticky 不强制。
- 主按钮全宽，字号≥16px 防 iOS 缩放。

## 5. 键盘与无障碍

- 拖放区是真 `<button>`/label，可 Tab 聚焦、Enter/Space 打开文件选择；粘贴监听挂在该卡片，聚焦时生效。
- 全程 `aria-live="polite"` 状态区播报：压缩中 / 判卷中 / 成功（题目数）/ 失败原因；错误条 `role="alert"`。
- checkbox 与说明文字 `<label>` 关联；灯箱沿用现有 ESC/焦点陷阱。
- 焦点顺序：入口按钮 → 上传区 → 预览删除 → 同意框 → 提交 → 结果区（成功后焦点移至结果标题 `tabindex="-1"`）。

## 6. 服务端对接约定

复用作文 API 进程与鉴权 key、每分钟限流、并发上限；作文/数学共用每日 50 次预算，仅新增一个 mode 参数区分，不新增表结构。前端提交为 multipart 单图 + 固定提示词，无文字模式字段；响应为结构化 JSON（题号/作答/判定/批注/总体说明），前端只做渲染不猜分、不补总分。

**约束确认**：两个静态示例的 HTML、图片、表格内容零改动；实时区为纯增量插入，样式全部挂在 essay.css/math.css 现有类上，仅新增少量 `.live-*` 工具类。
