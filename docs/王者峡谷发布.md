已加入张牧个人作品集，2026-09-15 发布，站点版本 `1.0.21`。

- 漫游页面：<https://liangz77.cn/mu/kings-canyon/>

现有 Caddy 使用 `handle_path /mu/*` 映射到 `current/apps/works/`。物理目录沿用 `apps/works`，公开链接统一使用 `/mu/`。新增峡谷无需修改服务器路由、新增后端或启动 Node 服务。

## 文件与入口

- `apps/works/kings-canyon/`：网页构建产物，包括 JS、CSS、GLB 模型、地形碰撞数据和 HDR 天空。
- `data.js` → `张牧作品` → `网页应用`：作品清单。
- `apps/works/portfolio.js`：卡片顺序、介绍和标签。
- `apps/works/previews/kings-canyon.png`：网页真实三维渲染截图。
- `apps/works/index.html`：作品集入口与无脚本时的备用链接。

峡谷支持步行、空格跳跃、沿视线方向飞行、穿模、小地图传送、手机摇杆和三档画质。它是经典峡谷的艺术重建与浏览体验，不包含对战玩法。
