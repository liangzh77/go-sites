# School AI Demo · 批改作文页面设计规范

路径：`/school-ai-demo/essay-review.html` ｜ 纯 HTML/CSS/JS，Go 后端提供两个接口：`POST /api/essay-review`（文本）、`POST /api/essay-review-image`（multipart 图片）。**不写库，不落盘用户内容，请求结束即弃。**

## 1. 信息架构（单页四区块，自上而下）

1. **顶栏**：复用主站顶栏，品牌「School AI Demo」+ 当前页标题「批改作文」。
2. **示例区**（默认折叠展开第一个）：两张卡片并列两个固定示例，各含「作文输入（手写照片）」缩略图 + 「AI 点评示例」文本块。每卡顶部置醒目角标：`预置示例 · 非本次实时生成`（徽章样式，非强调橙实底，避免与生成结果混淆）。
3. **提示词区**：灰底卡片展示统一提示词原文（“作为小学语文老师，给出真实，口语化评价……”），右侧「复制」按钮。
4. **试试你的作文**：输入区（Tab 切换「文本 / 图片」）+ 结果区。

页脚小字：模型 `DeepSeek-V4.1 Flash`；图片经同意后送往现有模型服务分析；不保存、不公开任何输入。

## 2. 布局尺寸

- 内容容器 `max-width: 880px; margin: 0 auto; padding: 24px 16px 64px`。
- 示例区桌面双列（`grid-template-columns: 1fr 1fr; gap: 20px`），<640px 单列。
- 输入 Tab：`text-align:center`，两个半宽按钮，高 44px。
- 文本框 `min-height: 200px`；字数统计 `x/8000` 右下角常驻，超限红色并禁用提交。
- 图片预览：最大高 240px，右上「× 移除」按钮 32px 圆形。

按钮：主按钮橙底白字、圆角 10px、高 44px；禁用态透明度 0.5 且 `cursor:not-allowed`。

## 4. 关键组件与状态

**示例图片**：缩略图 `<figure>`，点击打开灯箱（全屏半透明黑罩 + 图片 + 关闭按钮），支持 Esc 关闭、点击遮罩关闭。示例仅静态展示，**示例图片与点评均不发送 API**。

**复制按钮**（提示词、生成结果各一）：点击用 `navigator.clipboard`（失败降级 `execCommand`），成功文案变「已复制 ✓」2 秒后还原。

**输入切换**：显式 Tab，切换时清空另一种输入并在 UI 仅保留当前模式的提交通道；提交 payload 只含当前模式字段。图片模式三个入口：「选择图片」按钮（移动端也可用，`<input type="file" accept="image/jpeg,image/png,image/webp">`）、粘贴监听（`document.addEventListener('paste')` 读取 `clipboardData.items`）、拖拽（桌面）。

**同意与提示**：图片模式下常驻提示「上传前请遮盖姓名、学校、联系方式」；首次上传需勾选「同意将图片送往模型服务分析」复选框，否则提交禁用。

**生成结果**：卡片带左边框 4px 橙色，顶部小字「本次实时生成 · DeepSeek-V4.1 Flash」，正文为百字内第二人称评语，右上复制按钮。与示例卡片视觉差异明显（示例=米白底+徽章，结果=白底+橙边）。

## 5. 状态机

| 状态 | 表现 |
|---|---|
| 空态 | 无输入时提交禁用；结果区显示占位「点评会出现在这里」（浅灰虚线框） |
| 提交中 | 按钮变 spinner +「生成中…」，禁用；**防重复请求**：提交即置锁，响应后解锁；倒计时显示「最长约 120 秒」 |
| 成功 | 结果卡渲染，平滑滚动至结果 |
| 失败 | 错误条（浅红底）：「生成失败，请稍后重试」+ 重试按钮 |
| 额度不足 | 后端 429/余额错误映射为「今日额度不足，请明天再来」，禁用提交 |
| 模型不能读图 | 后端探测到模型不支持图片时，图片 Tab 禁用并显示「当前模型暂不支持图片点评，请使用文本输入」；**不静默降级文本、不换模型** |

**限制校验（前端先行，后端兜底）**：文字 ≤8000 字；图片 ≤5MB、仅 JPEG/PNG/WebP；前端 `AbortController` 120s 超时，提示「生成超时，请重试」。

## 6. 无障碍与移动端

- 所有图片有 `alt`（示例图：`示例作文手写照片 1`）。
- Tab 用 `role="tablist"`，箭头键切换；灯箱 `role="dialog"` + 焦点圈定。
- 所有交互元素焦点可见（`--focus-ring`），按钮可键盘触发。
- 结果区 `aria-live="polite"`，生成完成自动播报；错误条 `role="alert"`。
- 移动端：按钮触控目标 ≥44px；粘贴不便时上传按钮始终可见；灯箱图片支持双指缩放（`<img>` 原生 + `touch-action`）；字号正文 16px 防 iOS 聚焦缩放。
- 颜色对比度正文 ≥4.5:1，徽章文字用 `--text-dim` 深阶保证可读。

## 7. 实现注意点

- 图片上传前前端压缩非必需，但需 `FileReader` 生成预览；移除时清空 `<input>` 值以便重选同一文件。
- 请求头携带模式标识；后端对 multipart 做 MIME 嗅探而非仅信扩展名。
- 错误按 HTTP 码分类映射文案，不向前端暴露原始错误栈。
- 页面源码中模型名、提示词均为静态文本，便于日后替换。
