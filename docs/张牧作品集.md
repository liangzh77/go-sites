# 张牧作品集

独立入口：`https://liangz77.cn/mu/`。访问 `/mu` 会永久跳转到 `/mu/`。

## 结构与维护

- `apps/works/index.html`：独立作品集页面，不依赖主站页面或登录配置。
- `apps/works/portfolio.css`：米白、炭黑、黄绿色的视觉样式和响应式布局。
- `apps/works/portfolio.js`：从 `data.js` 的「张牧作品」读取完整目录，生成作品卡片、分类数量、筛选和随机游戏入口。
- `apps/works/previews/`：本站游戏的实际浏览器截图。
- `apps/works/fonts/`：本地字体及其许可证。页面无外部字体、脚本或图片请求。
- `Caddyfile`：`/mu/*` 映射到 `apps/works/*`，现有游戏路径保持有效。

新增作品时，更新 `data.js` 的「张牧作品」分类即可自动进入此页面；如需专属封面、简短介绍和展示顺序，在 `portfolio.js` 的 `details` 中增加对应项，并保存截图。未配置封面的作品显示文字封面。本站作品当前标签页打开；外部网站使用新标签页并明确标注。

页面采用现有静态 HTML/CSS/JavaScript 架构，不增加构建步骤。默认完整展示全部作品，JavaScript 关闭时提供直接访问的备用链接；目录加载失败时显示重试入口。

## 验证与发布

使用 `deploy.ps1` 发布。发布前检查 320、390、768、1024、1440 像素宽度、全部/游戏/网页筛选、随机游戏跳转、键盘导航、失败重试和 `prefers-reduced-motion`。发布后检查 `/mu` 跳转、6 个作品、全部静态资源以及已有 `/mu/游戏名/` 地址。

回退时恢复上一静态发布目录；如同时回退 `/mu` 重定向，需恢复相应 Caddyfile 并重新加载。
