## 接口

- `GET /api/demo/monitor/oceanengine/{run}/{event}`：成功持久化后返回 200 `ok`。HEAD 只检查可达性，不记事件；其他方法返回405。
- run 格式：`chuangliang-YYYYMMDD-` 后接6–24位小写字母或数字。
- event：`impression`、`click`、`video-start`、`video-finish`。
- `GET /api/demo/monitor/events?run=...`：沿用网站登录Cookie保护，只读查询；未登录401。

仅保存 UTC 接收时间、run、event，不记录参数、IP、Cookie、请求头。单进程每秒最多20条，超过返回429；最多256条记录，新回调清理7天以前记录，查询过滤过期记录。原子替换 `DEMO_DATA_DIR/monitor-events.json`；存储损坏或写入失败返回503，不覆盖损坏源文件。测试服务不用于高吞吐计费或生产归因；任何人都可能请求公开回调，记录中的 `unverified-http-callback` 不能当成真实广告曝光或点击。
